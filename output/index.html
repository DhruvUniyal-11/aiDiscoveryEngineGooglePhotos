📌 Core Executive Discoveries & Research Insights

This engine synthesizes public user evidence to map the vague-memory retrieval funnel in Google Photos. Operating under a strict non-solutioning constraint, it generates qualitative research intelligence to inform primary user interviews.

📍 Primary Failure Concentration

Failures concentrate heavily at Stage 2 (System Understanding Gap) and Stage 6 (Session Abandonment Locus). Users retain natural setting descriptions (e.g., 'Goa café', 'medicine bottle when sick'), but standard search parsers fail to map non-standard descriptive queries to visual index tags.

🧠 Memory Clue Retention Asymmetry

Users naturally remember Place / Setting (82%), Relative Time (78%), Visual Framing (65%), and Event Context (60%), while consistently forgetting exact dates, commercial place names, album titles, and face tag names.

📐 Official Retrieval Failure Taxonomy (7 Stages & 12 Categories)

Standardized taxonomy framework for mapping user memory friction and system capability gaps.

7 Failure Funnel Stages

  • Stage 1 User Cannot Express Memory (Expression Gap)
  • Stage 2 System Cannot Understand Memory (Intent Gap)
  • Stage 3 System Understands but Retrieves Poor Candidates (Ranking Gap)
  • Stage 4 Candidates Exist but Are Hard to Evaluate (Recognition Gap)
  • Stage 5 User Cannot Effectively Refine Search (Refinement Gap)
  • Stage 6 User Abandons Before Resolving (Abandonment Locus)
